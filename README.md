# Haq

Haq is a hackathon prototype for helping people act on documented rights involving failed payments, delayed MSME dues, and unclaimed assets in India.

## T0 status

This project begins with contract-first technical scaffolding. Initial API responses are fixed demo fixtures only: no legal rule is calculated, no real statement is parsed, no user data is persisted, and no complaint is filed.

## Safety

- Use synthetic or genuinely redacted examples only.
- Never commit bank statements, PAN, Aadhaar, account numbers, or other personal data.
- `data/real/` must remain ignored.
- Do not treat demo outputs as legal advice or filing-ready drafts.

Detailed setup and the T0 API contract will be documented as the foundation is added.
